# Vanguard Dental Group — Boutique Dental Studio Concept

A high-converting, luxury static landing page designed specifically for boutique cosmetic, restorative, and general dental practices.

Built with a modern aesthetic to showcase high-ticket clinical procedures (porcelain veneers, Invisalign® Diamond, dental implants, 3D digital imaging).

---

## 🌟 Key Features

- **Strict 100vh Desktop Hero:** Full viewport containment locking primary value proposition, Doctor profile card (`Dr. Elena Varga`), and 4 clinical accreditations above the fold.
- **Flawless Mobile Experience:** Sticky frosted glass header (`backdrop-filter: blur(16px)`), tap-to-call phone buttons, balanced 2×2 accreditation badge grid, and zero horizontal spilling.
- **Patient Financing & PPO Insurance Showcase (`#insurance`):**
  - Flexible 0% APR patient financing cards (**CareCredit®**, **Cherry®**, **Sunbit®**).
  - Recognized PPO insurance network badges (**Delta Dental**, **Aetna**, **MetLife**, **Cigna**, **Guardian**, **BCBS**, **UnitedHealthcare**, **Humana**).
- **Location & Google Maps Integration (`#location`):**
  - Custom dark-mode interactive map mockup of Brooklyn Heights.
  - Subway transit markers (Clark St 2/3 & Court St 4/5/R).
  - Dedicated logistics card with validated parking instructions and clinic hours.
- **High-Performance Static Architecture:**
  - Removed bulky client hydration bundles to deliver instant (<300ms) page loads.
  - Fully responsive across desktop (1440px+), tablet (1024px), and mobile (375px).

## 🚀 Quick Start / Local Preview

You can preview the landing page with any standard local HTTP server:

### Using Python:
```bash
python3 -m http.server 8000
```

### Using Node / npx:
```bash
npx serve . -p 8000
```

Then visit [http://localhost:8000](http://localhost:8000) in your browser.
